# ace2mqtt

Home Assistant add-on repository for Alfen EV chargers. The add-on reads
charger status and offers MQTT controls with Home Assistant Discovery.

See the [ace2mqtt setup and usage guide](ace2mqtt/README.md) for installation,
configuration, entities, controls and development notes.

This project is based on [`alfenctl`](https://github.com/pbasista/alfenctl),
created by [Peter Basista](https://github.com/pbasista). Thanks for building
and sharing the Alfen communication and CLI project this add-on uses.
